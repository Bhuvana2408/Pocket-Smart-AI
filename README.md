# 💰 Pocket Smart AI

Pocket Smart AI is an AI-powered personal budget and expense management system developed using FastAPI, Python, SQLite, SQLAlchemy, and Gemini AI.

The system helps users manage their expenses, create budgets, monitor spending, view reports, receive budget alerts, and get AI-powered spending recommendations.

## 🌐 Project Website

[Open Pocket Smart AI](http://127.0.0.1:8000/login-page)


## 🚀 Features

- 🔐 User Registration and Login
- 💸 Expense Management
- 💰 Budget Management
- 📊 Dashboard
- 🤖 AI Spending Recommendations
- 🔔 Budget Alerts
- 📈 Expense and Budget Reports
- 📜 Expense and Budget History
- 📋 AI Recommendation History
